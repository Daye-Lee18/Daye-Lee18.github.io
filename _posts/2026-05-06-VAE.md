## 1. VAE (Variational Autoencoder) 요약

VAE는 데이터를 생성하는 잠재 변수(Latent Variable) 모델로, 데이터 $x$의 분포 $p(x)$를 학습하는 생성 모델입니다.

### 핵심 개념
*   **잠재 변수 모델 (Latent Variable Model):** 관측 데이터 $x$가 직접 관측되지 않는 잠재 변수 $z$로부터 생성되었다고 가정합니다 ($z \to x$).
*   **문제점:** 실제 posterior $p(z|x)$를 계산하는 것이 불가능(Intractable)합니다. 왜냐하면 $p(x) = \int p(x|z)p(z)dz$를 모든 $z$에 대해 적분하는 것이 매우 어렵기 때문입니다.
*   **해결책 (Variational Inference):** 다루기 어려운 $p(z|x)$ 대신, 다루기 쉬운 분포 $q_\phi(z|x)$ (주로 가우시안)를 도입하여 이를 근사합니다.

### KL Divergence (Kullback-Leibler Divergence) 란?
KL Divergence는 두 확률 분포의 **차이(Difference)**를 측정하는 지표입니다. VAE에서는 우리가 가정한 분포 $q(z|x)$가 실제 분포 $p(z|x)$ (또는 Prior $p(z)$)와 얼마나 다른지를 측정하는 데 사용됩니다.

*   **정의:** 분포 $P$와 $Q$ 사이의 KL Divergence는 다음과 같이 정의됩니다.
    $$D_{KL}(P || Q) = \mathbb{E}_{x \sim P} \left[ \log \frac{P(x)}{Q(x)} \right] = \int P(x) \log \frac{P(x)}{Q(x)} dx$$
*   **특징:**
    1.  **항상 0 이상:** $D_{KL}(P || Q) \geq 0$이며, 두 분포가 완전히 같을 때만 0이 됩니다. (Gibbs' Inequality)
    2.  **비대칭성 (Non-symmetric):** $D_{KL}(P || Q) \neq D_{KL}(Q || P)$ 입니다. 따라서 엄밀한 의미의 '거리(Metric)' 함수는 아니며, **상대 엔트로피(Relative Entropy)**라고도 불립니다.
    3.  **VAE에서의 역할:** 인코더가 만들어낸 잠재 변수의 분포($q$)가 사전에 설정한 표준 정규 분포($p$)의 형태를 크게 벗어나지 않도록 강제하는 **규제화(Regularization)** 역할을 수행합니다.

### 목적 함수: ELBO (Evidence Lower Bound)
데이터의 로그 우도 $\log p(x)$를 직접 최대화하는 대신, 그 하한선인 ELBO를 최대화합니다.
$$\log p(x) \geq \mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)] - D_{KL}(q_\phi(z|x) || p(z))$$
*   **첫 번째 항 (Reconstruction Loss):** $z$로부터 $x$를 얼마나 잘 복원하는지 측정합니다.
*   **두 번째 항 (Regularization Loss):** 근사 posterior $q(z|x)$가 사전 분포 $p(z)$ (주로 표준 정규분포)와 얼마나 유사한지 측정합니다.

## 2. MLE (Maximum Likelihood Estimation) 수학 문제

**[문제]** 독립적인 $n$개의 데이터 $X = \{x_1, x_2, \dots, x_n\}$이 평균이 $\mu$이고 분산이 $\sigma^2$인 정규분포 $\mathcal{N}(\mu, \sigma^2)$에서 추출되었다고 가정할 때, $\mu$와 $\sigma^2$의 최대 우도 추정치(MLE)를 구하시오.

**[풀이]**
1. 우도 함수(Likelihood function) $L(\mu, \sigma^2)$ 정의:
   $$L(\mu, \sigma^2) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x_i-\mu)^2}{2\sigma^2}\right)$$

2. 로그 우도 함수(Log-likelihood function) $l(\mu, \sigma^2)$ 계산:
   $$l(\mu, \sigma^2) = -\frac{n}{2}\log(2\pi) - \frac{n}{2}\log(\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (x_i-\mu)^2$$

3. $\mu$에 대해 편미분하여 0이 되는 지점 찾기:
   $$\frac{\partial l}{\partial \mu} = \frac{1}{\sigma^2}\sum_{i=1}^n (x_i-\mu) = 0 \implies \hat{\mu} = \frac{1}{n}\sum_{i=1}^n x_i \text{ (표본평균)}$$

4. $\sigma^2$에 대해 편미분하여 0이 되는 지점 찾기:
   $$\frac{\partial l}{\partial \sigma^2} = -\frac{n}{2\sigma^2} + \frac{1}{2(\sigma^2)^2}\sum_{i=1}^n (x_i-\mu)^2 = 0 \implies \hat{\sigma}^2 = \frac{1}{n}\sum_{i=1}^n (x_i-\hat{\mu})^2$$

## 3. 시험 대비 수학 문제 (VAE/ELBO 유도)

**[문제]** 데이터 $x$와 잠재 변수 $z$에 대하여, 근사 분포 $q(z|x)$와 실제 Posterior $p(z|x)$ 사이의 KL Divergence를 이용하여 ELBO 식을 유도하고, 왜 ELBO를 최대화하는 것이 $\log p(x)$를 최대화하는 것과 연관되는지 설명하시오.

**[풀이]**
1. KL Divergence의 정의로부터 시작합니다:
   $$D_{KL}(q(z|x) || p(z|x)) = \mathbb{E}_{q(z|x)} \left[ \log \frac{q(z|x)}{p(z|x)} \right]$$

2. 베이즈 정리 $p(z|x) = \frac{p(x, z)}{p(x)}$를 대입합니다:
   $$D_{KL}(q(z|x) || p(z|x)) = \mathbb{E}_{q(z|x)} \left[ \log \frac{q(z|x)p(x)}{p(x, z)} \right]$$
   $$D_{KL}(q(z|x) || p(z|x)) = \mathbb{E}_{q(z|x)} [ \log q(z|x) - \log p(x, z) + \log p(x) ]$$

3. $\log p(x)$는 $z$에 의존하지 않으므로 기댓값 밖으로 나옵니다:
   $$D_{KL}(q(z|x) || p(z|x)) = \log p(x) + \mathbb{E}_{q(z|x)} [ \log q(z|x) - \log p(x, z) ]$$

4. 식을 $\log p(x)$에 대해 정리합니다:
   $$\log p(x) = D_{KL}(q(z|x) || p(z|x)) + \mathbb{E}_{q(z|x)} [ \log p(x, z) - \log q(z|x) ]$$

5. 여기서 우측의 기댓값 항이 바로 **ELBO**입니다:
   $$\text{ELBO} = \mathbb{E}_{q(z|x)} [ \log p(x, z) - \log q(z|x) ]$$
   또한 $p(x, z) = p(x|z)p(z)$이므로:
   $$\text{ELBO} = \mathbb{E}_{q(z|x)} [ \log p(x|z) ] - D_{KL}(q(z|x) || p(z))$$

**[설명]**
$D_{KL}$은 항상 0 이상이므로, $\log p(x) \geq \text{ELBO}$ 성립합니다. 따라서 ELBO는 $\log p(x)$의 하한선(Lower Bound)이 됩니다. $D_{KL}(q(z|x) || p(z|x))$를 최소화하는 것(근사 분포를 실제 posterior에 가깝게 만드는 것)은 곧 ELBO를 최대화하는 것과 같으며, 이는 데이터의 우도 $\log p(x)$를 간접적으로 최대화하는 효과를 가집니다.
